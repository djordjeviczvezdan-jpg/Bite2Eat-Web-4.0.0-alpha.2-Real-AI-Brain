# Bite2Eat 3.1.0-alpha.1 — Profitability Engine

Adds live profitability reporting using existing paid orders, recipes and ingredient costs.

## Included
- Revenue, food cost, gross profit and gross margin KPIs
- Recipe coverage warning for incomplete costing
- Profit per menu item and per order
- Menu engineering classifications: Star, Workhorse, Puzzle and Dog
- Range filters for today, 7, 30 and 90 days
- Tenant-isolated owner/manager API
- Links from Admin and Analytics

No new database tables are required. Results are calculated live from orders and recipe costs.
