# Bite2Eat 1.7.1-alpha.1 — Live Kitchen Updates

- Adds authenticated Server-Sent Events for live kitchen order updates.
- New paid or cash orders appear without refreshing the page.
- Existing order status/payment changes stream to every connected kitchen display.
- New-order bell and toast trigger on newly received tickets.
- Connection indicator shows Live connected or Reconnecting.
- Falls back to an eight-second refresh when streaming is unavailable.
