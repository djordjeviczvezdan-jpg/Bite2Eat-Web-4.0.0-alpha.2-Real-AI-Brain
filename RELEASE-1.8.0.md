# Bite2Eat 1.8.0-alpha.1

## Customer live order tracking

- Public customer tracking page for every order.
- Live Server-Sent Events status updates from the kitchen.
- Automatic fallback polling when a proxy blocks live streams.
- Separate collection and delivery progress stages.
- Live connection/reconnecting indicator.
- Status-specific ETA and customer messages.
- Delivery address and complete order summary.
- Existing payment-success and cash-confirmation flows link to tracking.
