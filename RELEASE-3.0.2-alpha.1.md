# Bite2Eat 3.0.2-alpha.1 — Recipes & Automatic Stock

- Optional Recipes & automatic stock module that depends on Inventory.
- Recipe builder for every menu item.
- Supports kg/g and L/ml conversions plus pieces.
- Live recipe cost and gross-margin preview.
- Idempotent ingredient deductions when an order becomes Completed.
- Stock movements retain an order audit reference.
- Restaurants can keep Inventory enabled while Recipes remain disabled.
