# Bite2Eat 3.2.0-alpha.1 — Restaurant Coach Daily Brief

Adds a restaurant-owner daily brief at `/r/[slug]/coach` with health score, yesterday revenue/profit/orders, stock and retention signals, and evidence-based action cards linked to existing Bite2Eat tools. This first release is deterministic and uses the restaurant's own database; it does not require an OpenAI API key and does not make automatic business changes.
